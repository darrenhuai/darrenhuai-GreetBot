# Contributing

GreetBot is a robotics and computer vision project. Contributions should make the project easier to understand, run, test, or adapt to new hardware.

## Good contribution areas

- Clearer setup documentation
- Hardware integration notes
- Dependency cleanup
- Small utility tests
- Demo scripts
- Error handling around camera or serial startup

## Development guidelines

- Keep commits focused and descriptive.
- Document hardware assumptions when changing robot-control behavior.
- Avoid committing local datasets, generated files, or machine-specific paths.
- Prefer small reusable functions over large demo-only scripts.

## Pull request checklist

- [ ] Explain the change clearly.
- [ ] Mention any hardware required to test it.
- [ ] Include screenshots or logs if helpful.
- [ ] Note any dependency changes.
